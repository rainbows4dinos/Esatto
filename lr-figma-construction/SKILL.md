# Figma Construction

## Purpose

Translate visual designs, prototypes, or design
explorations into editable Figma artifacts.

## Core principles

1. Preserve the source design's visual intent.
2. Reuse existing Figma components and tokens.
3. Do not create new tokens or styles unless authorized.
4. Use raw values for exploratory properties.
5. Prefer auto layout over absolute positioning.
6. Maintain logical layer hierarchy and naming.
7. Preserve existing production designs.

## Workflow

1. Inspect the target Figma document.
2. Identify reusable components and styles.
3. Plan the layer and layout structure.
4. Construct using native Figma elements.
5. Apply existing tokens and components.
6. Verify visual fidelity and construction quality.

## Quality requirements

- Frames use sensible nested auto layout.
- Text remains editable.
- Components resize predictably.
- Existing variables are properly bound.
- No unnecessary absolute positioning.
- Existing design system assets remain unchanged.
